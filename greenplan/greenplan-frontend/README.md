
# GreenPlan, интерфейс

Клиентское приложение GreenPlan для загрузки DXF-подосновы, настройки параметров озеленения и просмотра результатов расчёта.

Стек: React 19, TypeScript, Vite. Двумерный план отображается на Canvas, трёхмерная визуализация реализована с помощью three.js.

## Требования

- Node.js 22 (как в Docker-сборке).
- npm.
- Запущенный бэкенд GreenPlan.

## Локальный запуск

Из каталога `greenplan-frontend`:

```bash
npm ci
npm run dev
```

Vite запускает приложение по адресу `http://localhost:5173`.

По умолчанию запросы к API направляются на `http://127.0.0.1:8000`. Если бэкенд доступен по другому адресу, перед запуском задайте переменную `VITE_API_URL`.

PowerShell:

```powershell
$env:VITE_API_URL = "http://127.0.0.1:8000"
npm run dev
```

Указанный адрес должен соответствовать адресу, по которому бэкенд доступен из браузера.

## Сборка и просмотр

Проверка TypeScript и production-сборка:

```bash
npm run build
```

Собранные файлы размещаются в каталоге `dist/`.

Для локального просмотра production-сборки:

```bash
npm run preview
```

Vite Preview использует порт `4173`.

## Запуск через Docker

Из корневого каталога проекта:

```bash
docker compose up --build
```

В Docker-сборке переменная `VITE_API_URL` по умолчанию имеет значение `/api`. Nginx раздаёт собранное приложение и проксирует запросы `/api/` к бэкенду `api:8000`.

После запуска:

- Интерфейс: `http://localhost:8080`.
- Swagger API: `http://localhost:8000/docs`.

Nginx настроен на приём запросов с телом размером до 200 МБ и кеширование статических ресурсов из `/assets/`.

## Основные файлы

- `src/api.ts` — взаимодействие с HTTP API.
- `src/App.tsx` — корневой компонент приложения.
- `src/screens/` — экраны приложения.
- `src/components/` — переиспользуемые компоненты.
- `vite.config.ts` — конфигурация Vite.
- `Dockerfile` — production-сборка фронтенда.
- `nginx.conf` — конфигурация Nginx.
