# GreenPlan

Автоматизированное формирование плана озеленения по исходному DXF.

## Возможности

- чтение исходного DXF;
- распознавание объектов по слоям;
- обработка МАФ и урн;
- определение границы участка;
- применение нормативных ограничений;
- генерация кандидатов на регулярной hexagonal grid;
- проверка минимального расстояния между посадками;
- формирование размещений и отклонений;
- запись результата в отдельный DXF-слой;
- формирование JSON с объяснением решений;
- предупреждения о неизвестных слоях.
